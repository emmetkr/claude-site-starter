The six steps.

Do them in order. Each one is a free download and a sign-in.

  1. 1

    Install VS Code.

    The editor everything else runs inside. code.visualstudio.com

  2. 2

    Install the Claude Code extension.

    Open VS Code, find Claude Code in Extensions, and sign in with your Claude account. claude.com/claude-code

  3. 3

    Connect GitHub.

    Install GitHub Desktop and sign in. Every change is saved there, and it is how the site goes live. desktop.github.com

  4. 4

    Add the skills.

    In Claude Code, add impeccable. It reviews the design and catches the things that make a page look generated. The typeface, Inter, is already in this kit.

  5. 5

    Give Claude references.

    Clone awesome-design-systems into the reference/ folder: a list of 140 public design systems, from Adobe to Shopify, with links to each one. Save three sites you like there too (File → Save Page As). Ask Claude to study them before it designs anything.

  6. 6

    Describe your site in plain English.

    Open this folder in VS Code, start Claude Code, and say what the site is for and who reads it. Run node scripts/serve.mjs, open localhost:4173, and ask for changes the way you would brief a designer. For a product demo video, add HyperFrames: it turns HTML into video, so Claude can make the demo too.

What is in the kit.

Click Use this template on GitHub and you get your own copy of all of it.

CLAUDE.md

Tells Claude how the repo works, and that the docs and the code change together.

DESIGN.md

The colour and type tokens, and the list of design tells to avoid.

docs/copy-rules.md

The ten rules the copy follows. No hedging, no fragments, no tails.

docs/design-rules.md

Layout, components and the phone rules. Everything is checked at 390px wide.

scripts/probe.mjs

Screenshots the site at phone and laptop width so Claude can see its own work.

scripts/check.mjs

Finds unbalanced tags and missing files before a page ships.

mobile.css + mobile.js

The phone patterns: horizontal rails, segmented swipe tabs and bottom sheets, switched on by one attribute.

docs/mobile-patterns.md

The 390px measurements: rhythm, type, buttons, every section type.

scripts/serve.mjs

Opens the site at localhost:4173 while you work.

scripts/share-card.mjs

Renders the image that shows when your link is pasted into Slack or LinkedIn.

docs/DEVLOG.md

One dated line per change. Claude reads it at the start of each session, so it remembers.

reference/

Where the design systems and saved sites go.
