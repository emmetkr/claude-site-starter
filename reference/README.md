# Reference

Save pages you admire here, and ask Claude to read them before it designs.

In Chrome or Safari: File → Save Page As → "Web Page, Complete". Save into this folder, one subfolder per site:

```
reference/
  stripe-com/
  linear-app/
  rogo-com/
```

Then, in Claude Code: "Read the three sites in reference/. Note the type sizes, the section spacing and how they handle phones. Use those proportions for our site."

These files are for study. Do not copy text, images or logos from them into your site.
