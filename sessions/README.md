# Sessions

One short note per chat, so the next chat picks up where this one stopped. Claude reads the newest two at the start of every session and writes one at the end.

File name: `YYYY-MM-DD-<topic>.md`. Contents, three lines or so:

- **Did:** what changed, in plain words.
- **Decided:** anything the owner ruled on (a colour, a wording, a thing they rejected).
- **Next:** what was left open.

Longer-lived rules go in `docs/`, not here. This folder is the short-term memory; `docs/DEVLOG.md` is the long one.
